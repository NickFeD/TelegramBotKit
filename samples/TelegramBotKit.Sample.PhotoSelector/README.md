# Пример TelegramBotKit Photo Selector

Закрытый polling-бот индексирует новые фото и MP4-видео из явно включённых групп Telegram. Пользователи с доступом просматривают материалы по одному, выбирают нужные и скачивают исходники без потери качества. Telegram Bot API не даёт боту читать старую историю чата, поэтому индексируются только новые сообщения.

## Настройка и запуск

1. Создайте бота через BotFather. Убедитесь, что он получает нужные сообщения из группы: на это влияет режим приватности бота.
2. Храните токен вне репозитория. Для Visual Studio и VS Code удобнее всего использовать User Secrets:

   ```powershell
   dotnet user-secrets set "TelegramBotKit:Token" "123456:replace-me" --project samples/TelegramBotKit.Sample.PhotoSelector
   ```

   Или задайте переменную окружения перед запуском:

   ```powershell
   $env:TELEGRAM_BOT_TOKEN = "123456:replace-me"
   ```

   Переменная из встроенного терминала не попадает в уже работающий процесс расширения VS Code. В этом случае используйте User Secrets, запускайте бот из этого терминала или перезапустите VS Code после сохранения постоянной переменной окружения.

3. Запустите пример:

   ```powershell
   dotnet run --project samples/TelegramBotKit.Sample.PhotoSelector
   ```

База SQLite находится в `data/photo-selector.db` относительно каталога приложения. Миграции EF Core применяются автоматически при старте.

Первый реальный пользователь, отправивший боту сообщение в личном чате, становится администратором. Сообщения из групп, публикации каналов, служебные события и сообщения других ботов не могут создать первого администратора.

## Команды

- `/start`, `/whoami` — доступны всем в личном чате.
- `/browse`, `/liked`, `/skipped`, `/all`, `/sources`, `/topics`, `/export` — доступны пользователям с разрешением.
- `/access_grant <telegram_user_id>`, `/access_revoke <telegram_user_id>`, `/access_list` — только администратору бота.
- `/source_enable`, `/source_disable` — администратору внутри нужной группы или супергруппы.

При каждом запуске бот очищает стандартные области меню команд и заново создаёт русские меню. В личных чатах список зависит от роли в базе. Команды управления источником Telegram показывает администраторам групп, а обработчик дополнительно проверяет роль администратора бота.

## Оригиналы и preview

- Обычные фото и видео Telegram уже имеют повторно используемый `file_id` и показываются напрямую.
- Фото, отправленное как документ, и MP4-видео, отправленное как документ, сохраняются в базе как оригиналы.
- Идентификатор `Thumbnail` нельзя отправить через `sendPhoto`. При первом просмотре бот скачивает оригинал размером до 20 МБ в память, отправляет его как фото или потоковое видео и сохраняет полученный preview `file_id` рядом с `OriginalFileId`.
- Временный файл на диске не создаётся. После отправки поток памяти освобождается, а сами файлы хранятся Telegram.
- Если оригинал больше 20 МБ или Telegram не может преобразовать его, бот показывает исходный документ.
- Команда `/export` всегда отправляет исходный `OriginalFileId`, а не сжатый preview.

## Миграции

Из каталога проекта, предварительно установив `dotnet-ef` при необходимости:

```powershell
dotnet ef migrations add <MigrationName>
dotnet ef database update
```
